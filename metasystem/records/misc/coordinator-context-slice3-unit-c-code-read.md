## Answers to the specific questions

1. **Conformance.** Every unit C obligation I could check is implemented: the exact public signatures (`Handoff`, `HandoffDir`, `CancelHandoff`, `VerifyHandoffState`, `PruneContext`, `HandoffCaller`, `ScratchArg`, `HandoffRefusal`, `HandoffResult`, `ContextPruneResult`) match the brief verbatim; admission order 1-5 is implemented with the one deviation in F-12; state schema 1 carries every named member plus `schemaVersion`; the caps are 50/20/50 with five landing rows; `state.json` is bounded by `output.MaxInlineBytes` (32 KiB, `internal/output/output.go:20`); nonce is 16 lowercase hex minted from `crypto/rand`; supersession, cancellation and preparation share one arbitration section through `prepareIntentUnderLock`; `ConsumedIntent` is used so a reaped consumed record still verifies. Every named test exists and, with the exceptions in F-3, F-6 and F-14, asserts what its row claims. Deviations: F-1 (refusal after the directory exists), F-8 (size and unbriefed subsystem), F-12, F-14, F-15.
2. **What is captured, and whether it can mislead.** Seat, held goal, next step, open jobs, last landings, scratch, messages owed, optional manifest and the disposable sentence are all present, and every mutable record is copied into the nonce directory with a digest-and-byte-count verified reference plus a live source pointer, so later lawful job progress cannot invalidate the snapshot (asserted at `handoff_capture_test.go:195`-`:200`). Caps and overflow are enforced and the manifest is digest-pinned. Staleness: F-10 is the one field that can name something the same call deletes. Forgery: for a MAIN every identity field is taken from the caller unchecked apart from `Machine`, which must equal the accepted claimant (`handoff_capture.go:555`); the predecessor PID is never probed at capture time, so a wrong announcement produces a handoff whose predecessor is already dead. That is the brief's chosen boundary ("For a main use its announcement identity"), so I record it, not report it. For a DELEGATE every fact is rebound from the active job record and caller-supplied custody is discarded (proved by M14). Oversize refuses before any authority is minted, at the cost of F-1. Absence: optional scratch is explicitly `status: "missing"` with no copy, and `validateHandoffReference` refuses a required reference that claims to be missing (`handoff_state.go:195`-`:202`).
3. **Evidence loss, supersession and deletion.** Supersession preserves both immutable directories and writes an exact `cancelled: superseded by <nonce>` tombstone from a durable journal; the replacement state and brief are durable before the predecessor loses authority; every partial failure reports whether the old authorization is live, gone-with-unknown-durability, or unreadable. Deletion is journal-authorized: the tree is renamed into a private namespace, only members named in the journal with matching bytes and digests are unlinked, and anything undeclared refuses and is preserved (M30, M31, M33 all killed; `TestContextPruneRecoveryPreservesUnauthorizedEvidence`). Consumed records, briefs, intents, the registry and published week reports are never touched. The one loss-shaped act that is not recoverable is F-1's residue, which is retention of evidence rather than loss, and F-11's untruthful report line.
4. **Retention.** `PruneContext` removes only a regular non-symlink `handoffs/<nonce>` directory that is neither live nor consumed-active and whose `state.json` mtime is strictly older than `now - olderThan`; the protected check precedes any age or validity check, so a held handoff is safe at any age (M24 and M51 killed; `TestContextPruneKeepsLiveHandoffs` ages a live handoff to -30 d). Cutoff equality is retained (M25 killed). Live-to-consumed cannot open a window, because both sets are read under the same arbitration the mint, cancel and consume paths use (`TestContextPruneSerializesWithConsumption`). A still-needed handoff can be caught only after its consumed record is reaped, which the brief authorizes. The cutoff does refuse rather than clamp, but that refusal has no test (F-3), and the composition with usage's own wall-clock floor makes the effective bound depend on when the call runs and on the 14-day floor (F-2).
