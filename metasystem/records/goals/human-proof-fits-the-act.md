Human authority is proven by walking the invoking process's ancestry: it refuses any agent signature and must arrive at the exact terminal enrolled in that checkout (internal/humanauthority/authority.go; the enrollment record artifacts/agents/authority/human-terminal.json binds one terminal id, one terminal process and one session leader). The mechanism is right and must stay: an agent with a shell in the checkout would otherwise approve its own goals and raise its own budgets by typing --by. But its shape costs more than it should. Three defects, all seen this morning on m1d: (1) every human act demands the same proof, so stopping a session, which only halts work, is as hard as approving a budget, which grants authority; the seat's Stop hook refuses the turn end and the only graceful exit is an act that needs a live enrolled terminal, so a human away from that terminal can end the session only by killing the process; (2) enrollment binds ONE terminal line, so Wido enrolled at 07:48 on /dev/ttys010 and the very next command, typed in another tab, refused TERMINAL_NOT_REACHED; (3) the refusals name a missing file or an error code and never the repair, so neither 'human authority has no readable terminal enrollment' nor TERMINAL_NOT_REACHED tells the human to run goal enroll-terminal, and enrolling needs no prior enrollment, a fact nothing states. DONE means: the proof required is graded by what the act enables, so acts that only stop, park or release work are proven by a human at ANY terminal of that host (no agent signature anywhere in the ancestry, the walk reaching a terminal, the enrolled one or not), while acts that grant or widen authority (approve, set-budget, unapprove, accept-risk, set-obligation, resume, the classification sweep and enroll-terminal itself) keep the full enrolled-terminal walk unchanged; a human at any live terminal can always reach the stop path, so no seat can ever be wedged by a dead terminal; more than one terminal may hold an enrollment at once, or the refusal states that re-enrolling from any live terminal restores authority and that no prior enrollment is required; and every refusal in the authority layer prints one command that would have succeeded or says in words that none would.
