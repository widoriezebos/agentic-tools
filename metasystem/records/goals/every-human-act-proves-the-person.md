- Tier: 3
- Intent: What: Every act that only a person may do checks that a person really did it, and acts that widen what the machinery may do ask for the strongest proof, the person's enrolled terminal. Why: On 2026-09-13 two security sub-goals were folded away without any code. Today goal migrate, goal repair, reconciliation and the engine's pin step still accept a typed name with no proof behind it, and goal resume, setting a pin, steward arm, brain withdraw and resolve-taint accept any caller that is not an agent, including a relayed word. Before unattended seats hold a seat, a session must not be able to act as the person through one of these gaps. Pros: closes the remaining routes by which an agent could act in the person's name. Cons: touches security-critical code on many verbs, and a person will occasionally have to run an act at the enrolled terminal that used to work anywhere.

Done when: a test run as an agent (not the enrolled terminal) is refused on every act in the list, and each act still works from the enrolled terminal.
