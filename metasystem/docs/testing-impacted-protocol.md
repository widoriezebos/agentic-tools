# Impacted-test provider protocol
Agents call only `metasystem test impacted`. A repository delegates selection and execution with the optional `metasystem/testing.json` member `"impacted":{"cwd":".","argv":["./scripts/impacted-tests.sh"]}`. `cwd` and protocol paths are relative to the Git root; `.` is allowed. Argv executes directly, without shell interpolation. Exact argv[0] `metasystem` denotes the running binary. A missing member uses the full-test fallback. The wrapper starts the provider in `cwd` with inherited environment, no terminal, and no network entitlement. Standard input is exactly one UTF-8 JSON request followed by EOF. Standard output is exactly one UTF-8 JSON result plus whitespace; diagnostics and test logs belong on standard error. Missing, null, unknown, duplicate, wrongly typed, and trailing fields or documents are rejected. Negotiation is exact version 1; an unsupported provider diagnoses on standard error and exits nonzero, without downgrade. There is no implicit deadline. Cancellation sends `SIGTERM` to the provider process group, waits two seconds, then sends `SIGKILL` if anything remains; provider children must stay in that group. Providers run offline: Gradle uses `--offline`, Maven `-o`, and Go `GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local`. An unavailable offline dependency is `incomplete`. Provider exit 0 means stdout holds a valid result, including failed or incomplete tests. Every nonzero means no result even if stdout looks valid; the wrapper exits 2 with `TEST_IMPACT_EXECUTION_FAILED`. Ordinary test failures therefore emit failed JSON and exit 0. Example request: `{"schemaVersion":1,"mode":"run","base":"0123456789012345678901234567890123456789","repositoryRoot":"/workspace/project","changedPaths":["src/main/java/example/Thing.java"],"binding":"2ac42b0bf69e756a8beeb51b06ea572c9b3d60ab35110c13f6d1e72f20f47697"}`. Request JSON Schema: `{"$schema":"https://json-schema.org/draft/2020-12/schema","type":"object","additionalProperties":false,"required":["schemaVersion","mode","base","repositoryRoot","changedPaths","binding"],"properties":{"schemaVersion":{"const":1},"mode":{"enum":["run","list"]},"base":{"type":"string","pattern":"^(?:[0-9a-f]{40}|[0-9a-f]{64})$"},"repositoryRoot":{"type":"string","minLength":1},"changedPaths":{"type":"array","items":{"type":"string","minLength":1},"uniqueItems":true},"binding":{"type":"string","pattern":"^[0-9a-f]{64}$"}}}`. Mode is `run` or `list`; list selects without executing. Base is the resolved commit. Repository root is absolute and normalized. Changed paths are sorted, unique, normalized, repository-relative, may be empty, and preserve spaces. Binding is the lowercase SHA-256 evidence binding echoed by the result. Example result: `{"schemaVersion":1,"mode":"run","binding":"2ac42b0bf69e756a8beeb51b06ea572c9b3d60ab35110c13f6d1e72f20f47697","status":"passed","selections":[{"label":"unit","cwd":".","argv":["./gradlew","test","--offline","--tests","example.ThingTest"],"scope":"named","tests":["example.ThingTest"],"reasons":[{"test":"example.ThingTest","because":"changed source"}],"result":"passed","seconds":1.2}],"uncertainty":[]}`. Result JSON Schema: `{"$schema":"https://json-schema.org/draft/2020-12/schema","type":"object","additionalProperties":false,"required":["schemaVersion","mode","binding","status","selections","uncertainty"],"properties":{"schemaVersion":{"const":1},"mode":{"enum":["run","list"]},"binding":{"type":"string","pattern":"^[0-9a-f]{64}$"},"status":{"enum":["passed","failed","incomplete","listed","nothing-selected"]},"selections":{"type":"array","items":{"type":"object","additionalProperties":false,"required":["label","cwd","argv","scope","tests","reasons","result","seconds"],"properties":{"label":{"type":"string","minLength":1},"cwd":{"type":"string","minLength":1},"argv":{"type":"array","minItems":1,"items":{"type":"string"}},"scope":{"enum":["named","package","module","check"]},"tests":{"type":"array","items":{"type":"string"}},"reasons":{"type":"array","items":{"type":"object","additionalProperties":false,"required":["test","because"],"properties":{"test":{"type":"string","minLength":1},"because":{"type":"string","minLength":1}}}},"result":{"enum":["passed","failed","incomplete","not-run"]},"seconds":{"type":"number","minimum":0}}}},"uncertainty":{"type":"array","items":{"type":"object","additionalProperties":false,"required":["paths","because","action"],"properties":{"paths":{"type":"array","items":{"type":"string","minLength":1}},"because":{"type":"string","minLength":1},"action":{"type":"string","minLength":1}}}}}}`. Labels are unique/nonempty; argv[0] is nonempty and contains no NUL; seconds are finite/nonnegative; paths and cwd are normalized and repository-relative. Named scope requires names and a reason per name; package/module/check requires a `test:"*"` reason. Blocked commands may be not-run with an explanation. Uncertainty has paths plus nonempty because/action; empty paths means repository-wide. Run passed requires nonempty all-passed selections; failed requires a failure; incomplete requires an incomplete and no failure; empty means nothing-selected. List status is listed and selections are not-run with zero seconds. Run forbids listed. Only the wrapper emits top-level not-run for no groups. Version, mode, and binding match. Nothing-selected and incomplete are loud, never fabricated passing evidence. The following executable POSIX provider requires `jq` and conservatively selects the Gradle unit task; a Java team can replace that choice with `--tests` from `changedPaths` and use its JSON parser's duplicate-key rejection.

For named Gradle tests use `./gradlew test --offline --tests com.example.ThingTest`, scope named, each class/method in tests, and a matching reason. Test failure emits failed JSON; unavailable offline dependencies emit incomplete JSON; both exit 0. The envelope always has `schemaVersion`, nullable `request`, `implementation`, `result`, and `error`, plus `fallback` and `fallbackReason`. Exit 0 means passed, listed, nothing-selected, or the no-tests-declared exception; exit 1 means valid failed/incomplete execution; exit 2 means usage, configuration/input/protocol, launch, nonzero-provider, or cancellation error using `TEST_IMPACT_USAGE`, `TEST_IMPACT_CONFIG_INVALID`, `TEST_IMPACT_INPUT_INVALID`, `TEST_IMPACT_RESULT_INVALID`, or `TEST_IMPACT_EXECUTION_FAILED`.
