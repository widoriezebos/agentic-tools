# 3. The New Medium

Thesis: agentic labor is a different material with different failure
modes; the delivery system must be derived from its real
characteristics, not from habit.

## What disappears
Communication cost (context can be copied, not explained); knowledge
transfer (any worker can be instantiated with the full picture);
parallelism limits (ten independent attempts cost little more than
one); working hours, fatigue, motivation, ego; the scarcity of labor
itself.

## What appears
Statelessness: a worker's memory ends with its session, and continuity
exists only in records. Silent death: workers vanish mid-task without
a sound, and absence of output is indistinguishable from patience.
Plausible wrongness: fluent, confident, well-formatted work that is
subtly incorrect — the signature failure mode of the medium.
Sycophancy and drift: workers agree too easily and wander from intent.
No skin in the game: nothing an agent says is collateral; only
evidence counts. Identity: "which process is this, really" becomes a
correctness question, not an ops detail. And cost returns as a
per-token, per-attempt economics that human salaries had hidden.

## The asymmetry that organizes everything
Generation became cheap; verification did not. The scarce resource in
machine engineering is trustworthy judgment: proofs, discriminating
tests, independent review, grounded evidence. A system built for this
medium is organized around verification the way factories are
organized around their bottleneck.

## Consequences in one view
A table sketch: human limit removed / agent limit gained / what the
delivery system must therefore provide. This chapter closes with the
design brief the rest of the paper answers.
