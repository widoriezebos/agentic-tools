# 4. The Mimicry Trap

Thesis: the default path — making agents perform human ceremonies — is
comfortable, auditable-looking, and wrong.

## Skeuomorphism in process
Early cars looked like carriages; early agent processes look like
scrum. Agents writing standup summaries, sizing story points,
role-playing pull-request small talk: forms preserved after their
reason has evaporated, at real token cost, producing artifacts no one
— human or machine — actually needs.

## Why the trap is attractive
Familiar process feels governable: managers can read it, auditors can
recognize it, and nobody is fired for running agile. Mimicry also
hides a deeper comfort: it keeps the human in the old seat, reviewing
everything, which quietly caps the system at human speed.

## The cost of mimicry
Double ceremony (humans still meet about what the agents "met" about);
theater replacing proof (a well-written review comment from a model is
not scrutiny — an independent falsification attempt is); and the
worst: new, real failure modes going unmanaged because attention is
spent performing old ones.

## Extract the invariant, discard the form
The method this paper proposes: for every inherited practice, name the
invariant it protected, ask whether the new medium threatens that
invariant at all, and if it does, design machinery — not ritual — that
enforces it. Worked examples: standup → live state from records;
review → adversarial independent critique with mechanical gates;
estimation → budgets as enforced stop-laws; documentation → records
that are the system's actual memory rather than prose about it.
