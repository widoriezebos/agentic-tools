Registration records exact process identities, not descendants ([custody.go:3](/Users/wido/LocalStorage/GitHub/agentic-tools/metasystem/internal/dispatch/custody.go:3)); the census likewise recognizes job custody only by exact PID and start time ([run.go:266](/Users/wido/LocalStorage/GitHub/agentic-tools/metasystem/internal/census/run.go:266), [run.go:515](/Users/wido/LocalStorage/GitHub/agentic-tools/metasystem/internal/census/run.go:515)). More seriously, the reaper ignores `custodyProcesses`: after proving only the job record’s top-level adapter PID dead, it writes `groupDeathProvenAt` ([reaper.go:116](/Users/wido/LocalStorage/GitHub/agentic-tools/metasystem/internal/supervise/reaper.go:116), [reaper.go:133](/Users/wido/LocalStorage/GitHub/agentic-tools/metasystem/internal/supervise/reaper.go:133)). The real whole-group proof exists only in the kill-capable cancellation sweep ([dispatch.sh:285](/Users/wido/LocalStorage/GitHub/agentic-tools/metasystem/scripts/agents/dispatch.sh:285)). A daemonized server can also escape that process group.

   The design should say instead: register both the Go client and its exact server PID before protocol I/O; change the reaper so one dead PID can never establish group death; require the kill-capable owner to verify every registered identity and the process group before terminal compare-and-swap. 2. **CRITICAL — STRUCTURAL — The promised total permission table still does not exist, and valid ACP requests lack the facts needed to allow safely.**

   Evidence: r2 names a “total decision table” but supplies only general rules ([acp-transport-design.md:123](/Users/wido/LocalStorage/GitHub/agentic-tools/metasystem/plans/acp-transport-design.md:123)).    The design should say instead: deny or cancel every request until P1 establishes a versioned, machine-readable Devin request dialect. Then specify normalization and the full table: every tool kind; missing, multiple, canonicalized, and symlinked paths; mixed effects; network targets; all `tools` and `approvals` values; and deterministic offered-option selection. Never infer authority from human-readable titles, and never choose persistent `allow_always`; if no safe one-shot option is offered, cancel.

4. **HIGH — STRUCTURAL — The failure table is not complete against ACP v1.**

   Evidence: r2 claims to map “every stop reason” but lists only `end_turn`, `cancelled`, and `refusal` ([acp-transport-design.md:189](/Users/wido/LocalStorage/GitHub/agentic-tools/metasystem/plans/acp-transport-design.md:189)). ACP v1 also defines `max_tokens` and `max_turn_requests` ([StopReason schema](https://github.com/agentclientprotocol/agent-client-protocol/blob/main/schema/v1/schema.json#L3385-L3413)). The table handles a prompt error only, while JSON-RPC errors can occur during initialization, authentication, session creation/loading, prompt, and cancellation, and the schema admits standard and arbitrary error codes ([error schema](https://github.com/agentclientprotocol/agent-client-protocol/blob/main/schema/v1/schema.json#L3418-L3505)). ACP also defines many update kinds besides message chunks—tool calls, plans, modes, configuration, session information, and usage—plus extension notifications ([notification schemas](https://github.com/agentclientprotocol/agent-client-protocol/blob/main/schema/v1/schema.json#L3508-L3769)). None has an assigned journal, ignore, failure, or delivery outcome.

   Protocol version `1` is also insufficient to freeze this table: ACP’s schema artifact releases can evolve independently while retaining wire protocol version 1 ([ACP versioning](https://github.com/agentclientprotocol/agent-client-protocol/blob/main/README.md#L194-L206)).

   The design should say instead: pin the schema artifact release or digest used for implementation and tests. Provide a phase-by-phase matrix covering all response errors, malformed or mismatched IDs, every stop reason, every standard update kind, unsolicited server requests, cancellation races, and extension messages. Treat `max_tokens` and `max_turn_requests` as incomplete outcomes with chunks retained only as evidence; only a deliberate successful stop may enter delivery qualification.
