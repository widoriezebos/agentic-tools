## Build
1. `internal/landing/plain/steward_flake.go` (new). When the steward step (U2) sees the `confirmed-flake` row and the flake register (`FlakeRecorded`: fix goal and sighting count, written through `ProveSeams.RecordFlake`) shows two or more sightings of the same test with no fix goal yet, it opens the fix goal through the goal verbs' Go path (the same functions `goal open` and `goal approve` use — find them in cmd/metasystem/intent_goal*.go and internal/goal; never a shell): id `flake-fix-<package>-<test>` (lower-case, hyphens), tier 3, top priority, intent "the test <name> in <package> failed <n> times in the landing lane and was green on every named repeat (sightings with their load samples); make it hold under load without a wall clock (R-104: artificial clocks, never load-fragile tests)", basis = the sightings (attempt, log, load), next = "fix the test, run it 20 times under -p 4 with the package, hand it in". The register's `FixGoal` is written back. One goal per test; a second sighting of a test whose goal is open adds a sighting line to the goal's record instead (through the goal's note/record path if one exists; else the register alone). The act is an intervention record (Row confirmed-flake, What "opened flake-fix-...", Why the sightings, How the verbs).
2. The `confirmed-flake` row's prescription becomes "fix goal <id> is open (opened by the steward at <time>)" when the register names a goal, and "one more sighting opens its fix goal" when it does not.
3. The hourly report (U3) lists the flake goals opened and the ones still open under Quality.

## Tests
Fixture register with an injected clock and a fake goal-open seam that records the call: (a) one sighting → no goal, the row says one more; (b) two sightings → one goal with the id, tier, priority and intent above, FixGoal written back, one intervention line; (c) a third sighting → no second goal; (d) a person's own fix goal already named in the register → nothing opened; (e) the report lists it. Mutation: open on one sighting, or open twice → a test fails.
