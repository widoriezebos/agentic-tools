1. `internal/landing/state` (new package, no import of internal/landing/plain or lane): `Record` with `Lane` (Word: running|paused|stopped; Since; By; Reason), `Agent` (Session; Word: idle|stepping|step-process-gone|ended; Step; Since — see correction 1 item 8), `Batch` (ID; Execution: prepared|running|closed with its own Since; Admission: open|sealed with its own Since (sealed_at when sealed); Members; Base) — two independent facts, as batch.go:49 keeps them: a gate sets execution running while admission stays open (batch.go:829), the full proof seals admission while execution stays running (prove.go:694), `HandIns []HandIn` keyed by the submission's identity Goal+SHA+Ordinal (the ordinal of the queue line that recorded the submission; a SHA re-submitted after a return is a new entry, queue.go:204-226) (Word; Since; Reason; Hand-in time), `Resolution` (Goal; Word; Job; Since), `Proof` (Attempt; Scope; Word; Since; LoadAtStart), `Main` (Commit; Word: green|red|unproven; Since; OpenIncidents), `Questions []Question` (ID; Premise; Since), `Holds` (Barren int; SelectionPending bool; Since), `Engine` (Stamp), `Version int`. `Since` is `{At time.Time; Observed bool; Source string}`: a transition time (Observed false) or an observation (Observed true, Source = the raw record's file name); never a guessed time. `Event` {At; Kind; From; To; By; Evidence; Rebuild bool}. The package takes only `dir/state.lock` (internal/lock, exclusive, around every read-modify-write) and NEVER the installation or host lock: the installation lock has no reentrancy (internal/lock/file.go) and a calling verb may already hold it. `Transition(dir string, now time.Time, kind, from, to, by, evidence string, apply func(*Record)) (Event, error)`: reads `dir/state.json`, refuses (typed `*Refused` with the record's actual word, and appends a `defect` event) when the record's field named by kind is not in `from`, otherwise applies, appends one line to `dir/events.jsonl`, writes state.json atomically (temp file + rename). `Diff(a, b Record) []string` names every difference section by section — words, sinces AND payloads (a batch's members, a hand-in's reason, a question's premise, the open incidents) — as "batch.members: [A] → [A B]"; it is the ONE difference function, used by Replace here and by health in U2. `Replace(dir, now, next Record, by string) (changed []string, error)`: writes the whole record, appending one `rebuild` event listing `Diff(previous, next)`; an empty diff appends nothing. `Read(dir) (Record, bool, error)`. Callers may hold any lock or none; the package's own lock is the only one it takes.

## Tests

(e) membership drift: a shadow with batch members [A] while the raw batch (extendBatchLocked, batch.go:501) holds [A B] → `Diff` names `batch.members`, and the rebuild event lists it.
