Fix: walk the first-parent chain from the tip until the first commit that is main (the fetched main) or an ancestor of it; that commit is the base, and `merges` lists every member merge between it and the tip, in order. Test: a batch of two members where only the first member's tree fails an audit → cause "own" for that member, no main incident; a batch of one → unchanged; a red that reproduces on the true main prefix → "main".

Test: two reds on base A, then a resume on base B → the third check is admitted automatically; two reds on B → the person's question.
