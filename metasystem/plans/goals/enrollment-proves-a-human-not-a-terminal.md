# enrollment-proves-a-human-not-a-terminal

- State: queued
- Priority: 2
- Sequence: 11
- Risk: severity=3 novelty=2 exposure=3 accumulation=2 basis="severity 3: the enrolled terminal is the only thing separating an agent from every human-reserved act in a checkout, including stop, arm, approve, set-budget, steal and resume, and today an agent can create one; novelty 2: a second factor and its storage are new to this system, though the enrollment record and its generation already exist; exposure 3: every checkout on every machine, and the whole point of the stop verb's classifier depends on it; accumulation 2: every act performed through an agent-made enrollment is a ledger line that says a human typed it, and those accumulate unreadably"
- Tier: 3
- Intent: What: Enrolling a terminal proves that a person is there, with a one-time code from their authenticator app, instead of only proving that a terminal exists. Why: Today anything that can open a terminal, an agent starting tmux included, can enroll it and from then on pass every human-only gate in that checkout (approve, budgets, priority, resume, stop). It has already happened once, deliberately, on Wido's instruction. Parts exist elsewhere: one-time codes for the phone channel, browser sign-in with the seat's code, "signed in in the browser counts as the enrolled terminal", and the helm already lets GitHub Desktop commits through. Pros: Human-only gates really mean a human; it could make a remote approval lawful again and let graphical git clients commit with a code. Cons: An extra code at enrollment and renewal, existing enrollments must keep working through the change, and the work is security-critical.
- Origin: main
- Next step: Next: Design enrollment with a one-time code by reusing the existing channel code check and browser sign-in; say whether the helm already covers graphical git clients; and ask Wido in the same design whether relayed approval should return on top of it. Done when: Wido has accepted the design, and its first test shows one enrollment without a code refused and one with a valid code accepted.
