Slice one designs the loop: what feeds the draft queue, the draft format (evidence, cause, remedy, proposed appetite), the discussion surface (stop message + a review verb), and the two exits — scheduled (a goal open citing the draft) or dropped (recorded with the reason, so the same draft is not re-raised). RULING FOLDED IN (Wido 2026-08-25): the draft-first rule binds COORDINATORS today, not only the future machinery — small items (single-slice, ~2-3h, incident-derived under an existing ruling) go straight to the backlog with a proposed appetite; BIG tickets (arc-sized, multi-slice, cross-machine, or 4h+) are created as drafts and brought to Wido, and only his word opens the goal; an explicit in-conversation direction from him counts as the discussion. The design must make this threshold and flow mechanical. Slices then implement per the critique loop. METRIC RATIFIED (Wido 2026-08-25): PROCESS-TO-PAYLOAD RATIO is one of the loop's observed metrics — per concluded goal, compute dispatched rounds (job records), agent wall-clock, and correction-round count against the landed diff size and the appetite granted/spent; outliers in either direction (heavy process around a small payload, or a large landing with thin process) become draft-queue entries. All inputs exist as records today (jobs/, landings, goal history), so slice one's design must include this computation's shape and where its report surfaces (retro receipt or steward tick). METRIC FAMILY + NAMING LAW (Wido 2026-08-25 evening): metrics carry PLAIN HUMAN NAMES and every metric ships with its named action and owner or it does not ship (no metric without its action). The ratified candidates beside the overhead ratio (process-to-payload): Stale checks (when did each proof leg last actually run — run it or drop it from green's meaning); Rework rate (correction rounds + fix-forward commits per work item — fix the brief or the diagnosis); Friction rate (share of refusals blocking honest work vs catching defects — build the missing surface); Time waiting on checks (work-ready to landed, build vs proof split); Debt age (residue recorded to owned to closed); Built by delegates (share of landed product bytes by delegates vs coordinators); Cross-machine collisions (one machine invalidating the other, per class). Cost per result is context/trend only, not a trigger. All computable from existing records; slice one designs each metric's computation, threshold, action, and owner.
