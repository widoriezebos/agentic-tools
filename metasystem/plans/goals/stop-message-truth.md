# stop-message-truth

- State: queued
- Priority: 3
- Sequence: 7
- Risk: severity=2 novelty=1 exposure=3 accumulation=2 basis="severity 2: a wrong Stop judgement stalls a seat or hands it to the steward while it works, but grants nothing and destroys nothing; novelty 1: three local rules in the existing scanner and verdict; exposure 3: every seat's every Stop; accumulation 2: each stale hung flag and each miscounted idle refusal compounds until the seat is silenced or taken over"
- Tier: 3
- Intent: What: The message a session sees when it tries to stop tells the truth. A run that has finished is never called hung, acknowledging a hung run silences it, old finished runs are pruned like any other, the health line reads the right folder on seats laid out from the template, and the message names any worker or follow-up still running. Why: on every stop, dozens of runs that finished green in August still print "looks hung" and bury the one line that matters, and on some seats the health line calls live services dead. The goals this one waited on are done, so what is left is small. Pros: short, trustworthy stop messages, so sessions act on the real item. Cons: it touches the stop verdict every seat relies on, and a mistake could hide a run that really is hung.
- Origin: main
- Next step: Next: make a run that has ended never count as hung, and make an acknowledged hung run stop warning, with a test that seeds a finished run marked hung and an acknowledged one. Done when: that test is on main and a seat with old finished runs shows no "looks hung" lines for them at stop.
