- Intent: There is no way to record that a goal will never be worked and why. The states are queued, approved, claimed, parked and done; parked means resume later and is still live, still ranked, still counted against the one-claim quota. So a goal that cannot be pursued has to be forced through goal done with a conclusion explaining it was not done, which corrupts every count of completed work and makes readers parse prose to learn whether done meant done, or quietly dropped to the lowest priority band, which says nothing true and hides it. Two live specimens: account-provenance became permanently unresumable through a machinery defect, three verbs locked against each other, and its work is now carried by account-provenance-carried, so abandoning the record would be honest while the work continues; and the superseded metasystem-stop-design is reported as open work in every seat's end-of-turn scan. Wido's shape, 2026-09-08: move it out of the live set the way done goals move, keep it out of consideration for implementation, retain it with its reason rather than pruning it, because pruning loses the history. Codex was asked for a second opinion and argued against a marker on done, on the ground that anything which changes completion counts, dependency satisfaction, retention and reopening is a state whether or not it is named one; the code agrees. DONE means an explicit abandoned terminal state carrying its reason, excluded from goal next, the idle refusal, the ranked listing and the claim quota, satisfying no dependency, exempt from prune, reopenable by a human into queued, reachable for a breach-stopped goal, and proven by fixtures for each of those.
