# commit-goal-binding

- State: queued
- Priority: 2
- Sequence: 10
- Intent: What: Every commit on main is tied to a backlog goal, and any commit that slips through without one is reported. Why: The refusal half is done: an agent's landing without a goal it holds is refused. What is missing is the check afterwards: nothing looks at new commits on main to catch ones that went around the gate, such as hand commits. Pros: "Everything committed has a goal" becomes a checked rule, not just a request. Cons: Your own hand commits (like today's landings by hand while the lane is paused) would show up; they need a gentle warning so the check does not become noise.
- Origin: main
- Next step: Next: Add a steward check that walks new commits on main since its last position, looks for the goal trailer (Goal-Item), and raises one alert per commit without one; use the existing gentle warning for a person's own commits instead of a separate waiver record, unless you want one. Done when: tests with made-up commits show an unbound agent commit is reported once, a bound one is not, and a person's commit is reported as a warning.
