- Intent: Where the engine's supervision runs, tests that the engine starts keep their working areas in memory, on macOS and on Linux. An engine process creates that storage; the supervision reaper, which never uses it, releases it within two intervals after the last use, completes the cleanup at system stop, and recovers what a killed test left behind from recorded evidence, or reports it. A test binary only uses storage the engine has provided and proven; where no supervision runs nothing is created and tests use the disk as today. On managed storage a run builds the engine once per source state, not once per test binary. Nothing is left after tests are done; what cannot be released is a visible, firing row.
