# questions-with-a-default-do-not-block

- State: approved
- Priority: 1
- Sequence: 40
- Risk: severity=2 novelty=2 exposure=2 accumulation=2 basis="Lets seats act before a person answers, bounded to reversible steps; a wrong boundary could act where a person must decide"
- Tier: 2
- Intent: A seat that asks a person a question with a reversible default carries on with that default while the question waits (Wido 2026-10-03, lessons from m1f: from 00:07 to 02:15 m1f waited idle on 'where does run state go', and its own default was the answer chosen). The question says which choice the seat is taking meanwhile and what undoing it would cost; the person's later answer overrides it (R-142-m1e); irreversible or outward-facing steps (pushes to main, deletions, money) still wait. The steward no longer halts a seat whose open question carries a reversible default.
- Origin: main
- Next step: Short design: what makes a default reversible, how the seat records it and what it may do meanwhile, how a later different answer is applied; coordinate with channel-questions-stand-alone (the question message shows the default being taken); Astra critique tier 2; build.
