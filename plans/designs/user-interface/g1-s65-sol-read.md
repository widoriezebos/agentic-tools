**SOL-A-01 — High · material: yes · unfinished words can be lost.** The room saves on the first edit and on later edits at least a second apart; it has no save scheduled after the final keystroke ([room.ts:361](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/room.ts:361), [store.tsx:1780](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/partner/store.tsx:1780)). A last edit within that second remains only in browser memory if the human pauses and the page fails or reloads. Worse, `keepRoomNow` swallows a failed save, and Step out navigates after awaiting that swallowed failure ([store.tsx:1786](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/partner/store.tsx:1786), [ReviewRoom.tsx:131](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/ReviewRoom.tsx:131)). **Fix:** arrange a durable final save within the allowed frontend rules, and make Step out retain the room and show a refusal until its save is acknowledged. **R-124:** typed words are lost at ordinary first use.

**SOL-A-02 — High · material: yes · Clear to land can outlive its finding check.** End disables Clear only from the page’s current table ([ReviewRoom.tsx:307](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/ReviewRoom.tsx:307), [ReviewRoom.tsx:359](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/ReviewRoom.tsx:359)). The service accepts the chosen verdict without checking the record ([service.go:1123](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/partner/service.go:1123)); recording the Outcome also lacks that check ([store.tsx:1616](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/partner/store.tsx:1616)). If another tab records an unanswered finding after Clear was chosen, the first Outcome write conflicts and rereads the record, but a second **Record it** press can still write the already offered Clear card ([recording.ts:159](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/partner/recording.ts:159)). **Fix:** validate the current record’s unanswered findings when composing or saving a Clear Outcome, including after conflict rereads. **R-124:** this records false clearance as authoritative review intent.

**SOL-A-03 — Medium · material: yes · the desk can show the old tip under the new tip’s header.** Review the new tip updates `Reviewed:` but does not invalidate the desk ([store.tsx:1844](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/partner/store.tsx:1844)). Desk component and read keys contain the item path and range, but no reviewed commit or record revision ([Desk.tsx:21](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/Desk.tsx:21), [Desk.tsx:84](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/Desk.tsx:84), [Desk.tsx:121](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/Desk.tsx:121)). An open source, index, or diff therefore remains the prior read while the room identifies the new tip. **Fix:** key reads by the reviewed commit or invalidate and reload the desk after a successful retip. **R-124:** the human can examine the wrong code without a warning.

**SOL-A-04 — Medium · material: yes · done-goal source marks can claim another goal’s lines.** The change index correctly compares each landed `Goal-Item` commit with its first parent ([review.go:216](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/review/review.go:216)). Source highlighting instead diffs the first commit’s parent directly against the last landed commit ([review.go:575](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/review/review.go:575)). With another goal’s commit between those two, its added lines are marked as touched by the reviewed goal. **Fix:** derive marks from the selected per-commit comparisons and map them to the final source tree, or omit marks whose provenance cannot be established. **R-124:** the desk silently attributes code to the wrong change.

**SOL-A-05 — Medium · material: yes · a refused Start can create a second review record.** Start writes a new record before opening its sitting; if opening fails, the server returns that record’s path ([httpd/review.go:129](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/httpd/review.go:129)). The review door shows only the error text and drops the returned draft path ([Door.tsx:53](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/Door.tsx:53)), although the API exposes it for retry ([api.ts:508](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/partner/api.ts:508)). The next **Review it** creates another uniquely named record ([project/review.go:53](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/project/review.go:53)). **Fix:** retain the returned path and retry Start against that record, as the existing Start sheet does for other sittings. **R-124:** one attempted sitting leaves an orphan review and a second project record.

**SOL-A-06 — Medium · material: yes · Step out does not establish that an answer stopped.** On the second press, Step out calls a void, unawaited `stop()` and navigates ([ReviewRoom.tsx:131](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/ReviewRoom.tsx:131), [store.tsx:1005](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/partner/store.tsx:1005)). Server Stop discards the bounded settlement result and can return success before the terminal write ([service.go:1483](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/partner/service.go:1483)). **Fix:** make this press await Stop’s settlement and keep the room open with the specified refusal when it does not settle. **R-124:** a running answer may continue after the page says the human has stepped out and stopped it. The separate A-to-B turn handoff *does* check settlement.

**SOL-A-07 — Medium · material: yes · an Outcome can omit what was examined.** `outcomeWithVerdict` returns any draft starting with the selected `Verdict:` prefix without adding the `Examined:` text; it does not require an exact first line either ([room.ts:263](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/review/room.ts:263)). Thus `Verdict: clear to land` alone can be recorded, and `Verdict: clear to landing` passes the prefix check. Recording relies on this function ([store.tsx:1616](/Users/wido/LocalStorage/GitHub/agentic-tools-room/metasystem/internal/ui/web/_app/src/partner/store.tsx:1616)). **Fix:** validate the exact verdict line and require an examination statement before writing Outcome. **R-124:** a bare nod can become the review’s authoritative Outcome.
