## Pass 1, on the first three commits

**Read-only review: fixes are required before acceptance.** The most serious issue is that a human name can grant authority over another seat’s goal without human proof on a checkout whose brain is undeclared. Findings below are based on code reading; I made no edits and ran no tests.

## Findings

1. **High — `goal block` can treat an unproved human name as authority.** The CLI calls `syncReq` without proof ([goalsync_mutations.go:2030](../../../metasystem/cmd/metasystem/goalsync_mutations.go:2030)). With an explicit `--lineage`, request construction skips its ancestry proof path ([goalsync_mutations.go:615](../../../metasystem/cmd/metasystem/goalsync_mutations.go:615)); on an undeclared-brain checkout, classification does not reject an agent’s `--by` ([goalsync_mutations.go:685](../../../metasystem/cmd/metasystem/goalsync_mutations.go:685)). The engine exempts any nonempty `Actor.Human` from the held-goal check ([verbs.go:944](../../../metasystem/internal/goal/verbs.go:944)). **Scenario:** an agent supplies `--by Wido --lineage ...` and blocks another seat’s claimed X behind G, parking X and displacing its claimant without observed human proof. A direct engine caller can also supply the name alone. The new test helper does exactly that ([blockedges_test.go:22](../../../metasystem/internal/goal/blockedges_test.go:22)). A genuine seat actor with no human name is correctly limited to its own claim.

2. **High — a seat can use `--origin human` to evade the open rule.** `OpenRisked` requires `--blocks` only when the supplied origin is `main`, and checks proof only for a below-derived tier ([verbs.go:755](../../../metasystem/internal/goal/verbs.go:755)). The CLI passes `--origin` through ([goalsync_mutations.go:1765](../../../metasystem/cmd/metasystem/goalsync_mutations.go:1765)). **Scenario:** a seat opens N with `--origin human --blocked-by G`, no `--blocks`, and the derived tier. N publishes and parks although the seat did not open a blocker for the goal it holds, contrary to the [actor matrix:18](../../../plans/designs/user-interface/g1-s37-blocked-by-many-blocking-many.md:18).

3. **Medium — verified channel proof is refused for an early unblock.** The mutation calls `approvalProofClass` ([verbs.go:2783](../../../metasystem/internal/goal/verbs.go:2783)); the channel-aware approval gate is a different function ([approval.go:404](../../../metasystem/internal/goal/approval.go:404)). **Scenario:** a verified channel answer asks to remove unfinished G from X. The proof is rejected although [design line 21](../../../plans/designs/user-interface/g1-s37-blocked-by-many-blocking-many.md:21) admits it; its History provenance is never written. The session case uses `recordApprovalProof` and is covered, but the channel case is not.

4. **Medium — the stated recovery rule does not hold for human edge acts.** `block` journals `by`, but recovery refuses every journaled human verb outside its conditional set; that set excludes `block` ([verbs.go:2687](../../../metasystem/internal/goal/verbs.go:2687), [recover.go:154](../../../metasystem/internal/goal/recover.go:154), [recover.go:276](../../../metasystem/internal/goal/recover.go:276)). **Scenario:** a human blocks X behind G, then the owner dies before publication; recovery rejects the act instead of replaying `block` as [design line 22](../../../plans/designs/user-interface/g1-s37-blocked-by-many-blocking-many.md:22) says. A satisfied human `unblock` also cannot replay, although the design singles out *early* unblock for refusal. Replaying a stored name alone would be unsafe, so the recovery contract and authority mechanism need to be reconciled.

5. **Medium — direct `goal block` never records the promised `block` History verb.** The journal intent says `block`, but the dependent’s History says `edit` if already parked or the blocker is done, and `park` otherwise ([verbs.go:2687](../../../metasystem/internal/goal/verbs.go:2687), [verbs.go:950](../../../metasystem/internal/goal/verbs.go:950), [verbs.go:984](../../../metasystem/internal/goal/verbs.go:984)). **Scenario:** a reader auditing why X acquired G cannot find a `block` act in X’s History. The test explicitly requires `park` ([blockedges_test.go:279](../../../metasystem/internal/goal/blockedges_test.go:279)), contrary to [design line 23](../../../plans/designs/user-interface/g1-s37-blocked-by-many-blocking-many.md:23). No new History keys are involved.

6. **Medium — the persisted waiting reason can contradict the edge list.** Adding an edge to an already parked goal leaves `Parked.Because` unchanged ([verbs.go:947](../../../metasystem/internal/goal/verbs.go:947)); removing an edge updates it only when that edge was the marker ([verbs.go:2809](../../../metasystem/internal/goal/verbs.go:2809)). The backlog projects that text as `waiting.reason` ([project.go:297](../../../metasystem/internal/backlog/project.go:297)). **Scenario:** X parks behind A, then gains B. After A completes, X correctly remains parked, but its reason still says it returns when A is done. Removing a non-marker edge can likewise leave a removed goal in the reason.

## Checks that held, and proof still needed

By reading the mutations, I found no honest-seat path to change an unheld dependent or remove an unfinished edge: `block` checks the held claim, `unblock` checks it for satisfied edges and requires proof for early removal ([verbs.go:944](../../../metasystem/internal/goal/verbs.go:944), [verbs.go:2773](../../../metasystem/internal/goal/verbs.go:2773)). A multi-target open returns before publication on any target refusal; the shared parking path retains claim teardown, displacement, and the breach-fence refusal ([verbs.go:892](../../../metasystem/internal/goal/verbs.go:892), [verbs.go:967](../../../metasystem/internal/goal/verbs.go:967)). Its already-done decision is made inside the mutation.

The release check requires a dependency marker and every remaining blocker to be done; missing goals are not satisfied. Removing the marker rebinds it before publication, preserving the parser’s marker-in-list rule, while an ordinary park keeps its empty marker ([verbs.go:1056](../../../metasystem/internal/goal/verbs.go:1056), [verbs.go:2809](../../../metasystem/internal/goal/verbs.go:2809), [file.go:816](../../../metasystem/internal/goal/file.go:816)). Open journals both lists and recovery reconstructs them; the early-unblock replay is refused. The tests do not cover `block` replay or satisfied `unblock` replay ([recover.go:404](../../../metasystem/internal/goal/recover.go:404), [blockedges_test.go:554](../../../metasystem/internal/goal/blockedges_test.go:554)).

At the interface boundary, both list fields accept an absent value, empty value, comma string, or array. Both edge routes call `mayAct` and take the **dependent** from the path ([acts.go:140](../../../metasystem/internal/ui/httpd/acts.go:140), [acts.go:287](../../../metasystem/internal/ui/httpd/acts.go:287), [act.go:338](../../../metasystem/internal/ui/act/act.go:338)). The route test’s “early unblock” 409 is an injected refusal under a proven human, not evidence that the real signed-in act reaches the engine with proof ([edges_test.go:120](../../../metasystem/internal/ui/httpd/edges_test.go:120)).

Proposed receipt, not written: `Read-only review of b6247b828, ec597648b, and the engine-facing interface paths of 23fa6a750; six material findings; no edits or tests.`

**Verdict: accept after the listed fixes.**


## Pass 2, on the fourth commit

**The fourth commit fixes the six findings on the new block, unblock, and open paths, except for the park reason. The broader actor rule also still has an edit path around those verbs.**

1. **Still wrong across the engine:** the new edge verbs use proof, but [reconcile accepts a human name without proof](../../../metasystem/internal/goal/reconcilepub.go:30) and [applies `BlockedBy` edits directly](../../../metasystem/internal/goal/reconcilepub.go:429). In an undeclared checkout, a seat can hand-edit parked X from `[A,B]` to `[A]`, then reconcile with `--by Wido --lineage …`; unfinished B is removed without proof.
2. **Fixed as meant:** [the open gate uses `humanHand`, not origin](../../../metasystem/internal/goal/verbs.go:760), so an unproved seat cannot open without naming a goal it blocks.
3. **Fixed as meant:** [early unblock uses the approval gate that admits verified channel proof](../../../metasystem/internal/goal/verbs.go:2859), and [records that proof’s History provenance](../../../metasystem/internal/goal/verbs.go:2918).
4. **Fixed in the safe form:** [recovery replays seat `block` and satisfied `unblock`](../../../metasystem/internal/goal/recover.go:412), while [refusing an unlanded journaled human act](../../../metasystem/internal/goal/recover.go:154).
5. **Fixed as meant:** [direct `block` writes `block` to dependent History](../../../metasystem/internal/goal/verbs.go:2790).
6. **Still wrong:** [initial open builds `Because` from all blockers](../../../metasystem/internal/goal/verbs.go:877), so X opened behind done A and live B says it waits for both. [Abandon rewrites the reason to one remaining blocker](../../../metasystem/internal/goal/abandon.go:525), and [split changes the edge list without refreshing the reason](../../../metasystem/internal/goal/split.go:275); with several live blockers, the displayed reason becomes incomplete or names the retired parent.

**The finding 4 divergence is sound.** A stored human name cannot restore the proof that allowed a human `block` to reach an unheld goal. Recovery [checks whether the operation already landed first](../../../metasystem/internal/goal/recover.go:72), then refuses an unlanded human replay. The design’s blanket replay sentence should reflect that boundary.

**Additional open and attribution findings:** [OpenRisked](../../../metasystem/internal/goal/verbs.go:760) constrains an unproved seat’s targets but still [stores its requested `origin=human`](../../../metasystem/internal/goal/verbs.go:868). A seat holding X can open G with `--origin human --blocks X`; [the seat then cannot conclude G](../../../metasystem/internal/goal/verbs.go:2420). Also, [an explicit `--by` is never checked against the admitted proof’s identity](../../../metasystem/cmd/metasystem/goalsync_mutations.go:1384), so an enrolled terminal proof for Alice can publish an edge with Bob in History. Terminal ancestry open, a relay with `--by` and lineage while its existing time window permits it, and [the signed-in interface open](../../../metasystem/internal/ui/act/act.go:327) remain wired; I found no legitimate open path broken by the new gate.

**Remaining fixes before acceptance:** put proof and early-removal checks on every `BlockedBy` edit path, require proof for `origin=human` or store a seat’s open as `main`, derive park reasons from unfinished blockers on initial open and every edge rewrite, and bind a named human actor to the admitted proof. I made no edits and ran no tests.


## Pass 3, on the fifth and sixth commits

1. **Still wrong:** [reconcile’s edit helper](../../../metasystem/internal/goal/reconcilepub.go:250) lets an unproved seat remove a *done* edge from a goal it does not hold; [direct `Edit`](../../../metasystem/internal/goal/verbs.go:3401) still replaces the whole list without the helper. Leaving [reconcile’s open arm](../../../metasystem/internal/goal/reconcilepub.go:288) out is unsound: an unproved, named seat can hand-create a human-origin X blocked by live B, and it lands queued without a dependency park.
2. **Origin fixed, attribution still wrong:** [OpenRisked stores an unproved seat’s open as `main`](../../../metasystem/internal/goal/verbs.go:793), but [History still reads `Actor.Human`](../../../metasystem/internal/goal/verbs.go:897). A proofless request naming Wido and blocking its own held goal lands with `Origin=main` and `actor=human:Wido`; its journal also carries `by=Wido`.
3. **Still wrong across all rewrites:** initial open, abandon, and split now refresh the reason, but [direct `Edit`](../../../metasystem/internal/goal/verbs.go:3401) does not. Editing parked X from `[A,B]` to `[A]` can leave `Parked.Because` saying it waits for A and B.
4. **Exemptions sound; terminal binding still wrong:** a channel account ID is not a local name, and relay and fixture proofs carry no comparable identity. But [humanOfProof reads the *current* enrollment and treats read failure as no identity](../../../metasystem/internal/goal/verbs.go:1125), while [an old proof remains valid for the root](../../../metasystem/internal/humanauthority/authority.go:200). Capture Alice’s proof, re-enroll as Bob, then submit that proof with `--by Bob`: the new binding accepts the wrong attribution.

**New findings beyond those four: none.** Remaining fixes: apply the full seat and early-lift rules to every edit and hand-created open, including parking when a live blocker is added; attribute proofless seat acts as seats throughout Origin, History, and journal; refresh the park reason on direct edits; bind enrolled identity to the same enrollment observation as its proof and refuse an unreadable or changed enrollment. No edits or tests were performed.
