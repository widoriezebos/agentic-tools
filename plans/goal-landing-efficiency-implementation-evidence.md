## What changes

The testing planner and retained-result store own join, tip and prefix proof. Each prefix computes its own requirements and consumes compatible observations. Seal no longer owns a second native test gate. Current policy, input identity, freshness and live publication authority are checked when evidence is consumed.

Execution identity is separate from policy selection. Adding an unrelated group can reuse a prior group, while changing a consumed source, tool, declared external input or semantic environment invalidates it. The Go adapter generates package groups with transitive import inputs and declared shared runtime inputs. Application orchestration uses the same command/JUnit adapter as the portability fixture.

Admission freezes the complete selection and allocates missing producers atomically. Consumers retain original producer references and wait only on earlier reservations. Real prerequisites suppress dependent launches after a failure; independent failures can be collected together. Fresh diagnostics have durable episodes, so resuming the same episode can consume its observation while a new decision requires native execution.

The resource owner admits heavy work and exclusive resources. Its custody correction retains admission until native descendants and declared fixture children have demonstrably ended, including launcher or worker failure. Real public entrypoint, nested execution and failure canaries pass; the exact-candidate delivery proof remains outstanding.
